# Abstract

HumanoidTurk explores humanoid robots as haptic media for immersive virtual reality. The system translates in-game g-force signals into synchronized humanoid motion feedback for VR driving, demonstrating how humanoids can provide consistent, physically expressive feedback beyond conventional controllers.
